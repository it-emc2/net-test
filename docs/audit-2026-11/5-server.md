## What is done well (keep)
- Per-deal send lock for e-mail and post is atomic via unique index (`src/lib/sendLock.js`).
- Draft create is idempotent on `clientSaveId` and handles the unique-index race (`src/routes/drafts.js:86-103,174-180`).
- Price is always recomputed server-side on save; client pricing blobs are not trusted (`src/routes/offers.js:525-530`).
- Admin routes check role against the user record (`src/routes/admin.js:25-37`); passwords use scrypt with per-user salt and constant-time compare.
- Config values are cached in memory with periodic refresh (`src/services/configService.js`) — the pattern to reuse for products (S08).
- TTL indexes exist on BitrixLog, PdfLog, UserActionLog and the recording index collections.
